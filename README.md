# NexaTI Automação - Landing Page Conceitual

Landing page profissional criada para **NexaTI Automação**, marca fictícia desenvolvida para portfólio. O projeto apresenta uma oferta comercial plausível para automação de processos, integração de sistemas, soluções web, tratamento de dados e dashboards, sem declarar clientes, resultados ou métricas reais.

## Tecnologias Utilizadas

- HTML5 semântico
- CSS3 responsivo
- JavaScript vanilla
- SVG próprio para favicon

Não há frameworks, bibliotecas externas ou dependências obrigatórias.

## Estrutura

```text
landing-page-ti/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
├── assets/
│   └── favicon.svg
└── README.md
```

## Como Executar

Abra o arquivo `index.html` diretamente no navegador.

Também é possível servir a pasta com qualquer servidor local simples, caso queira testar em uma URL local antes de publicar.

## Funcionalidades Implementadas

- Header responsivo com menu mobile
- Hero section com visual tecnológico e CTA principal
- Navegação suave por links internos
- Seções de problemas, serviços, processo, diferenciais e exemplos de aplicação
- CTA final
- Formulário de contato ilustrativo com validação básica e sem envio real de dados
- Feedback visual de erro e sucesso no formulário
- CTA flutuante interno para contato com ícone de WhatsApp configurável em implementação real
- Animações progressivas ao entrar nas seções, com conteúdo visível sem JavaScript
- Estados de hover e focus
- SEO básico com title, meta description, Open Graph e metadados Twitter
- Acessibilidade com HTML semântico, labels, atributos ARIA, menu mobile controlado e respeito a redução de movimento
- Layout responsivo para desktop, notebook, tablet e celular

## Como Personalizar Para Um Cliente Real

1. Substitua o nome, identidade visual e textos pela marca real do cliente.
2. Atualize os serviços de acordo com as entregas oferecidas.
3. Troque os exemplos de aplicação por casos autorizados ou mantenha-os como cenários genéricos.
4. Configure o formulário para enviar dados a um e-mail, CRM, planilha ou backend.
5. Configure o canal de WhatsApp com um número oficial do cliente, se esse canal for usado.
6. Ajuste as metatags de Open Graph com a URL pública final.
7. Revise políticas, termos e textos legais quando o site for usado comercialmente.
